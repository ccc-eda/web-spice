# web-spice

在瀏覽器裡執行的 SPICE 電路模擬器。以 Node.js 工具鏈（esbuild）編譯後，產出**單一 `index.html`**：沒有後端、沒有執行期依賴，用瀏覽器直接開啟，或放到任何靜態主機（GitHub Pages、Netlify、S3…）即可使用。

輸入 SPICE 網表，按下「執行模擬」，就會得到**電路圖**與**波形圖**（或工作點表格）。

## 功能

- **分析類型**：`.op` 直流工作點、`.dc` 直流掃描、`.tran` 暫態、`.ac` 交流頻率響應（Bode 圖：增益與相位）
- **元件**：電阻 R、電容 C、電感 L、獨立電壓源 V、獨立電流源 I、二極體 D、電壓控制電壓源 E（可當理想運算放大器）
- **電源波形**：`DC`、`AC`、`SIN`、`PULSE`
- **自動繪製電路圖**：直接由網表產生 SVG，修改網表後會即時更新
- **示波器風格波形圖**：自製 Canvas 繪圖，含座標刻度、圖例、對數頻率軸
- **13 個內建範例**：分壓器、RC 充放電、RLC 振鈴、低通／帶通濾波器、並聯諧振、半波／橋式整流、二極體 I-V 曲線、反相放大器、削波器、微分電路、惠斯登電橋
- 支援淺色與深色模式；`Ctrl/⌘ + Enter` 快速執行

## 快速開始

需要 Node.js 18 以上。

```bash
npm install        # 安裝 esbuild（唯一的開發依賴）
npm run build      # 產生 dist/index.html（約 20 KB）
npm test           # 在 Node 中執行全部範例，並檢查電路圖是否能正確產生
```

建置完成後，用瀏覽器開啟 `dist/index.html` 即可。部署時只需要上傳這一個檔案。

## 專案結構

```
web-spice/
├── index.html          頁面模板（版面與樣式），建置時把程式碼嵌入 <!--APP-->
├── build.mjs           建置腳本：esbuild 打包 → 單一 dist/index.html
├── test.mjs            以 Node 執行所有範例的煙霧測試
└── src/
    ├── spice.js        模擬核心：網表解析、MNA 組矩陣、Newton-Raphson、各種分析
    ├── schematic.js    由網表產生 SVG 電路圖
    ├── examples.js     內建範例（名稱、說明、網表）
    └── main.js         介面：範例選單、執行、波形繪圖
```

`src/spice.js` 與 `src/schematic.js` 不依賴 DOM，可以直接在 Node 中使用：

```js
import { parse, run } from './src/spice.js';

const net = parse(`RC low-pass
V1 in 0 AC 1
R1 in out 1k
C1 out 0 159n
.ac dec 20 10 1meg
.plot ac v(out)`);

const result = run(net);   // { kind: 'ac', x: [頻率…], mag: [...], ph: [...] }
```

## 網表語法

- 第一行是**標題**（不是元件）。
- 以 `*` 開頭的行是註解，行內可用 `;` 加註解；以 `+` 開頭的行接續上一行。
- 大小寫不敏感；節點 `0`（或 `gnd`）為接地。
- 數值後綴：`f p n u m k meg g t`（`m` 是毫，百萬請寫 `meg`），例如 `4.7k`、`100n`、`1meg`。
- `.end` 之後的內容會被忽略。

### 元件

| 語法 | 說明 |
| --- | --- |
| `Rname n1 n2 值` | 電阻 |
| `Cname n1 n2 值` | 電容 |
| `Lname n1 n2 值` | 電感 |
| `Vname n+ n- [DC 值] [AC 值] [SIN(...)] [PULSE(...)]` | 獨立電壓源 |
| `Iname n+ n- …` | 獨立電流源，電流由 n+ 經元件流向 n-；參數同電壓源 |
| `Dname 陽極 陰極 [模型名]` | 二極體 |
| `Ename 輸出+ 輸出- 控制+ 控制- 增益` | 電壓控制電壓源（VCVS） |

電源只寫一個數字時視為 DC，例如 `V1 in 0 12`。

- `SIN(偏移 振幅 頻率 [延遲])`
- `PULSE(V1 V2 延遲 上升時間 下降時間 脈寬 週期)`

### 模型

```
.model dmod d is=1e-14 n=1.05
```

二極體目前支援 `IS`（飽和電流，預設 1e-14）與 `N`（發射係數，預設 1）。

### 分析指令

| 指令 | 說明 |
| --- | --- |
| `.op` | 直流工作點，列出所有節點電壓與電壓源／電感／E 元件電流 |
| `.dc 來源 起 止 步` | 直流掃描，例如 `.dc V1 0 1.5 0.01` |
| `.tran 步長 終點` | 暫態分析，例如 `.tran 20u 20m`（步數上限 50000） |
| `.ac dec 每十倍頻點數 起 止` | 交流分析，例如 `.ac dec 40 10 1meg` |
| `.plot v(節點) i(元件) …` | 指定要畫的訊號；省略時畫出所有節點電壓 |

`.plot` 可用 `v(節點)`，以及 `i(元件)`：支援電阻與電壓源／電感／E 元件。電壓源的電流以 SPICE 慣例定義（由 + 端流經電源到 − 端），因此電源供電時為負值。若要觀察支路電流，最簡單的做法是量測串聯電阻的 `i(r1)`。

若沒有任何分析指令，預設執行 `.op`。

### 範例

```
Half-wave rectifier
.model dmod d is=1e-14 n=1.05
V1 in 0 SIN(0 5 60)
D1 in out dmod
R1 out 0 1k
.tran 100u 50m
.plot tran v(in) v(out)
```

## 運作原理

1. **解析**（`parse`）：把網表轉成元件清單，節點以出現順序編號（接地為 0），並為 V、L、E 配置額外的支路電流未知數。
2. **修正節點分析（MNA）**：未知數為「節點電壓 + 支路電流」，每個元件依類型把「印記」寫入矩陣 `A` 與向量 `b`，再以部分選主元的高斯消去法求解 `A·x = b`。每個節點並聯 1e-12 S 的 gmin，避免矩陣奇異。
3. **非線性元件**：二極體以 Newton-Raphson 迭代求解（線性化為電導加等效電流源），並限制接面電壓上限以避免指數溢位；迭代進入後段時加入阻尼，改善切換時的收斂。
4. **暫態**：電容與電感使用後向歐拉（backward Euler）伴隨模型，以前一個時間點的解為歷史值。
5. **交流**：先求直流工作點並對二極體線性化，再對每個頻率組複數系統。複數以 2M × 2M 的實數區塊矩陣 `[[G, -B], [B, G]]` 表示，因此直流、暫態、交流共用同一個實數解法器。
6. **電路圖**：每個節點是一條垂直匯流線（最左為接地），每個元件佔一列橫跨其兩端節點；導線交叉處不加圓點表示不相連。這種版面不是傳統的紙上畫法，但對任何網表都保證連線正確。

## 限制

- 尚未支援 BJT、MOSFET、JFET、互感、傳輸線與子電路（`.subckt`）。
- 暫態使用後向歐拉法，有輕微數值阻尼；步長建議取訊號週期的 1/200 以下，否則共振波形的振幅會偏小。
- 二極體只實作理想 Shockley 方程式（無串聯電阻、接面電容與逆向崩潰）。
- 極端非線性電路仍可能出現「牛頓迭代未收斂」。
- 無自適應步長與初始條件指令（`.ic`），暫態一律從直流工作點開始。

## 擴充方式

- **新增範例**：在 `src/examples.js` 的陣列加入 `[名稱, 說明, 網表]`。
- **新增元件**：在 `src/spice.js` 的 `parse` 加入語法，在 `build` 的 `switch` 加入印記；若需要電路圖符號，在 `src/schematic.js` 的 `P` 表加入路徑，並在 `label` 加入標籤。
- **新增分析**：在 `run` 加入新的分析型別，並在 `src/main.js` 的 `draw` 決定顯示方式。
